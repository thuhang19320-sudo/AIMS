# Lab 01 - Environment Setup and Java Basics

Java programs for the assigned tasks: **2.2.5**, **2.2.6**, and **6.1 to 6.6**.

| Task | Java file |
|---|---|
| 2.2.5 | CalculateTwoNumbers.java |
| 2.2.6 | EquationSolver.java |
| 6.1 | ChoosingOption.java |
| 6.2 | InputFromKeyboard.java |
| 6.3 | TriangleStars.java |
| 6.4 | DaysOfMonth.java |
| 6.5 | ArrayStatistics.java |
| 6.6 | MatrixAddition.java |

Each class has its own `main` method and no Java package declaration.
Compile: `javac *.java` (PowerShell: `javac (Get-ChildItem *.java).Name`).
Run: `java TriangleStars` (replace with any class name).
`ChoosingOption` opens Swing dialog windows and requires a graphical desktop.

The assignment specifies Java 8; source code uses Java-8-compatible language features.
Check `answers.txt` for answers to exercise 6.1 questions.
